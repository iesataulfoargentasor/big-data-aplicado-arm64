AVISOS QUE PUEDEN SEGUIR APARECIENDO
No son avisos de arquitectura AMD64:
- SLF4J: más de una implementación de logging en las dependencias de Hive.
- Hadoop: módulos opcionales OpenSSL, ISA-L y PMDK no disponibles. Las pruebas
  no dependen de ellos; se usan las implementaciones Java cuando procede.
- Consola Trino sin terminal interactivo durante las pruebas automáticas.
- La configuración de Hive no incluye log4j.properties de Hadoop.

ALCANCE Y LIMITACIONES
Esta revisión valida lake, el cliente Hadoop, MapReduce/YARN, el flujo ELT
manual, el DAG real de Airflow y el clúster Kafka con su consola.
Los escenarios se ejecutaron por separado, no todos simultáneamente.
Los ejercicios son pequeños; no se garantiza capacidad para datos grandes,
trabajos simultáneos ni otros conectores o algoritmos nativos no probados.
Hive mantiene Tez local dentro de HiveServer2; no se presenta como Hive sobre YARN.
La versión y suma de Hadoop y el digest de Hive están fijados. Los paquetes
APT y algunas dependencias Python transitivas pueden cambiar en futuras construcciones.
El nuevo proyecto no reutiliza ni migra automáticamente los datos anteriores.
